# 功能范围与实施状态

| 模块 | 开源版实现 | 验证边界 |
| --- | --- | --- |
| POS | 商品搜索/扫码、数量/改价、挂单/取单、现金收款 | 现金账本自动测试通过，UI 待验收 |
| 商品与分类 | 本地资料、变体、批量启停、Excel | 类型与构建通过，UI 待验收 |
| 订单与退货 | 待付款创建/导入、本机收款、退货、小票 | 创建、收款、幂等自动测试通过；文件与打印需人工验收 |
| 看板 | 本机现金订单及退款 | 在线分支移除，显示需人工验收 |
| 本机设置 | 主题、语言、币种、设备、快捷键、JSON 备份 | 备份往返与冲突测试通过；设备真机另验 |
| 库存 | 不提供 | 无库存数量校验或扣减 |
| 云端/门店/员工/会员资产/在线支付 | 仅 Upgrade 占位 | 实现组件与云端代理已移除 |

`api.ts` 只调度本地账本。唯一保留的业务网络请求为显式启用的本机设备桥接，目标限制为 loopback。翻译字典及空备份兼容字段中仍保留部分历史词条，不构成高级功能实现。

## 目录

- `src/operate/`：POS、向导、小票和退货操作。
- `src/backend/kanban/`：业绩看板。
- `src/backend/order/`：订单、创建、导入、退货记录。
- `src/backend/product/`：商品、分类、批量启停、翻译。
- `src/backend/setting/`：本机设置与数据管理。
- `src/components/`：共享控件及升级说明。
- `src/*.ts`：本地账本、金额、导入校验及通用状态。
- `hardware/`：可选本机桥接程序，独立于云端。

本轮浏览器访问未获工具权限，未声称 UI 与 IndexedDB 已完成浏览器验证；自动测试使用隔离内存适配器。
